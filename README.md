# Fluxcord (Voice)
Fluxcord's voice component.

This is required if you want to host Fluxcord with Voice Bridging enabled.

## Self hosted setup

Check https://fluxcord.jbcrn.dev/self-hosting-voice for self hosting docs

## Development

Firstly, this requires both Node.js and PNPM installed.

**Do not clone this repo directly.** Instead, clone the Fluxcord Dev repository:

```
git clone https://git.gay/Fluxcord/dev Fluxcord
```

then initialize it:

```bash
cd Fluxcord
pnpm run init
```

If you use VSCode or a fork, you can find a code-workspace file here that can help you with stuff.
